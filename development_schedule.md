# PokerLeaguePro Development Schedule

This schedule outlines the remaining tasks to complete the PokerLeaguePro application, based on a 1-2 hour daily work session.

---

this schedule should reflect the task on complete-hebrew-pokerpro-prd.md

### Week 1: User Profile & Advanced League Management

- **Day 1:** Implement user profile picture uploading and display.
- **Day 2:** Add biographical information and a basic stats summary to the user profile page.
- **Day 3:** Implement public vs. private leagues and display the status in the league list.
- **Day 4:** Implement league roles (Admin, Member, Viewer) and display them in the member list.
- **Day 5:** Add the ability for a league admin to edit league details (name, description).

### Week 2: Game Management & Statistics

- **Day 6:** Implement the Game Admin transfer functionality.
- **Day 7:** Add location tagging and session notes to the game creation screen.
- **Day 8:** Create the individual player statistics screen with basic stats (Profit/Loss, ROI).
- **Day 9:** Implement the league-wide statistics screen with a simple leaderboard.
- **Day 10:** Add a basic profit/loss graph to the player statistics screen.

### Week 3: Social Features

- **Day 11:** Set up the basic structure for in-app messaging (league chat).
- **Day 12:** Implement sending and displaying messages in the league chat.
- **Day 13:** Create the UI for scheduling a game with a date/time picker.
- **Day 14:** Implement the RSVP functionality for scheduled games.
- **Day 15:** Design and implement a simple achievement system (e.g., "First Win" badge).

### Week 4: Monetization & Localization

- **Day 16:** Implement the freemium model by limiting the number of leagues for free users.
- **Day 17:** Add a "Go Premium" screen showing the benefits of the paid plan.
- **Day 18:** Integrate a basic in-app purchase flow for the premium subscription.
- **Day 19:** Begin implementing Hebrew translations for the main screens.
- **Day 20:** Implement RTL layout for the Hebrew language.
